# 🎨 Trudido v1.0.3 - "Dracula & Discoverability" Release

**Release Date**: October 13, 2025  
**Build**: Major UI/UX Overhaul  
**Compatibility**: Android 5.0+ (API 21+)

---

## 🌟 What's New

### 🧛 **Authentic Dracula Theme**
- **New Dark Theme**: Authentic Dracula color palette with deep purples and atmospheric colors
- **Auto Dark Mode**: Dracula theme automatically switches to dark mode for optimal experience
- **Authentic Colors**: Uses official Dracula color scheme (#BD93F9, #FF79C6, #8BE9FD, #282A36)
- **Special Theme Icon**: Distinctive moon icon for easy identification

### ✨ **Discoverable Name System**
- **Tap to Set Name**: No more hunting for buttons - just tap the greeting to set your name
- **Smart Hints**: First-time users see "Tap here to set your name" guidance
- **Clean After Clear**: Once you clear your name, no repetitive hints (you already know the feature!)
- **Easy Management**: Clear, Skip, or Change your name anytime through the greeting

### 🌍 **Enhanced Greeting System**
- **17 Languages**: Expanded from 11 to 17 greeting languages including Ukrainian, Turkish, Romanian
- **Smart Controls**: Choose between random greetings or fixed language preference
- **Proper Localization**: Fixed language mappings (French/German swap resolved)
- **Theme Integration**: Greetings now use your theme's primary colors

---

## 🎨 Visual Improvements

### **Theme Organization**
- **Organized Color Picker**: Standard Colors vs Special Themes sections
- **Better Navigation**: Cleaner theme selection with proper categorization
- **Consistent Icons**: Material Design 3 icons throughout the app

### **UI Polish**
- **Themed App Name**: "trudido" text now uses your selected theme's primary color
- **Styled Dividers**: Folder dropdown dividers match your theme colors
- **Updated Icons**: Filter icon changed from tune to filter_alt for better clarity
- **Color Harmony**: Greeting text uses primary color, subtitles use secondary color

## 🔧 Technical Improvements

### **State Management**
- **Unified Preferences**: Centralized preference system for better performance
- **Smart Name Handling**: Three distinct states - empty, skipped, cleared
- **Proper Persistence**: All settings persist correctly across app restarts

### **Internationalization**
- **Locale Fixes**: Corrected locale codes (cs_CZ, de_DE, es_ES, etc.)
- **Language Accuracy**: Fixed French ↔ German mapping issues
- **Expanded Support**: Added support for regional language variants

### **Bug Fixes**
- **Template Crashes**: Resolved PopupMenuButton conflicts causing crashes
- **Memory Optimization**: Cleaned up duplicate locale files
- **Theme Consistency**: Proper theme color application across all components
