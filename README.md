Trudido — Flutter Todo App

This repository contains a Flutter todo application.

Quick start

1. Install Flutter: https://flutter.dev/docs/get-started/install
2. Ensure Android SDK is configured and Android/iOS toolchains are set up.
3. From the project root:

```bash
flutter pub get
flutter run -d <device>
```

Notes

- This repo excludes machine-specific and sensitive files such as `android/local.properties`, keystores (`*.jks`/`*.keystore`), and service credentials (`google-services.json`, `GoogleService-Info.plist`).
- Internal notes were moved to `docs/internal/` and are not part of the public README.
