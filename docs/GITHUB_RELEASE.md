# 🎨 Trudido v1.0.3 - "Dracula & Discoverability"

_A major UI/UX overhaul that transforms how you interact with Trudido_

---

## 🚀 **What's New**

### 🧛 **Authentic Dracula Theme**

Experience coding in style with our brand-new **Dracula theme** featuring:

- 🎨 **Authentic Colors**: Official Dracula palette (#BD93F9, #FF79C6, #8BE9FD)
- 🌙 **Auto Dark Mode**: Automatically switches to dark mode for optimal experience
- ✨ **Atmospheric UI**: Deep purples and atmospheric colors perfect for night owls
- 🦇 **Special Icon**: Distinctive moon icon in theme selector

### 👆 **Revolutionary Name System**

Say goodbye to hunting for buttons! We've completely reimagined how you set your name:

- **Tap the Greeting**: Simply tap "Good morning!" to set your name - no more searching for buttons
- **Smart Hints**: First-time users see "Tap here to set your name" guidance
- **Clean Experience**: After clearing your name, no repetitive hints (you already know!)
- **Easy Management**: Clear, Skip, or Change your name anytime through the greeting text

### 🌍 **Enhanced Internationalization**

- **17 Languages**: Expanded from 11 to 17 greeting languages
  - Added: Ukrainian (Українська), Turkish (Türkçe), Romanian (Română)
- **Smart Controls**: Choose between random greetings or stick to your preferred language
- **Fixed Mappings**: Resolved French ↔ German language swap issue

---

## 🎨 **Visual Improvements**

### **Theme Organization**

- 📂 **Categorized Themes**: Clean separation between "Standard Colors" and "Special Themes"
- 🎨 **Better Discovery**: Easier to find and explore different theme options
- 🏷️ **Clear Labeling**: Each theme category is clearly marked

### **UI Polish Throughout**

- 🏷️ **Themed App Name**: "trudido" text now uses your selected theme's primary color
- 📋 **Styled Dividers**: Folder dropdown dividers match your theme colors
- 🔍 **Updated Icons**: Filter icon changed from tune to filter_alt for better clarity
- 🎨 **Color Harmony**: Greeting uses primary color, subtitles use secondary color
- ✨ **Consistent Design**: All UI elements now properly follow Material Design 3

---

## 🔧 **Technical Improvements**

### **Under the Hood**

- ⚡ **Unified Preferences**: Centralized preference system for better performance
- 🧠 **Smart State Management**: Three distinct name states (empty, skipped, cleared)
- 💾 **Reliable Persistence**: All settings persist correctly across app restarts
- 🗂️ **Code Cleanup**: Removed duplicate locale files, optimized memory usage

### **Bug Fixes**

- ✅ **Template Crashes**: Fixed PopupMenuButton conflicts that caused crashes
- ✅ **Language Issues**: Corrected locale codes (cs_CZ, de_DE, es_ES, etc.)
- ✅ **Theme Consistency**: All components now properly use theme colors
- ✅ **Memory Optimization**: Reduced resource usage through code cleanup

### **Requirements**

- 📱 Android 7.0+ (API 24+) recommended
- 📱 Android 5.0+ (API 21+) minimum
- 💾 ~15MB storage space

### **Installation**

1. **Download** the APK from the assets below
2. **Enable** "Install from Unknown Sources" in your device settings
3. **Install** and launch to experience the new features!
